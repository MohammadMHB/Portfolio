# Mohammad Mohebianfar — Portfolio

> Personal portfolio website for showcasing my work, technical skills, and selected projects as a Full-Stack Developer.

🌐 **Live Website:** https://mohammadmohebian.ir

## Overview

This repository contains my personal developer portfolio. It presents my technical background, selected projects, skills, education, and contact information through a responsive web experience.

## Highlights

- Responsive layout for desktop, tablet, and mobile
- Modern dark interface with glassmorphism-inspired UI
- Smooth scrolling and section animations
- Active navigation based on the current section
- Animated skills and statistics sections
- Selected project showcase
- Contact section
- Persian and English typography support

## Tech Stack

- **HTML5** — Semantic page structure
- **CSS3** — Flexbox, Grid, responsive design, custom properties
- **JavaScript (ES6+)** — Interactions and UI behavior
- **Intersection Observer API** — Scroll-based animations
- **LocalStorage** — Client-side form data handling
- **Vazirmatn** — Persian/English typography

## Sections

- Hero
- About
- Skills
- Education
- Projects
- Contact

## Getting Started

Clone the repository:

```bash
git clone https://github.com/MohammadMHB/Portfolio.git
cd Portfolio
```

Open the main HTML file in a browser, or serve the project with any static web server.
